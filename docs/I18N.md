# i18n status: N/A

Reason: The M0 application is an English-only expert-operated CLI with no
civic/public-service end-user workflow and no localized date, number, or
currency presentation.

Obligation Receipts is an English-only, expert-operated technical-alpha CLI. It
has no public-service workflow, HTML surface, translated catalog, or
locale-dependent parsing behavior. Internationalization is therefore not
applicable to M0.

This decision must be revisited before adding a reviewer UI, localized trace
reports, or an operator population with a declared language-access obligation.
Machine schemas, enum values, identifiers, and canonical serialization remain
locale-independent.

Entry point if this changes: introduce a gettext boundary for CLI and report
prose while keeping schema keys, enum values, identifiers, canonical JSON, and
digests locale-independent; then apply the portfolio catalog and parity gates.
